Online Course Website

This is my first web development project built with HTML and CSS, created as the final project for my course at Tehran Institude of Technology.

The UI design was provided in Figma, and I was responsible for converting the design into a functional multi-page website and implementing the user interface using HTML and CSS.

Through this project, I practiced translating a Figma design into real web pages, structuring multiple pages, and styling the interface based on the provided design.
